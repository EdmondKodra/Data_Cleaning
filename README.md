🧹 Data Cleaning Project

Ky projekt demonstron pastrimin dhe normalizimin e të dhënave duke përdorur Python dhe Pandas.

Veprimet kryesore:

🗑️ Eliminimi i kolonave të panevojshme dhe duplicate

✏️ Normalizimi i teksteve dhe numrave të telefonit

🏠 Ndarja e adresave në rrugë, shtet dhe kod postar

🚫 Filtrimi i të dhënave të pa plotësuara ose të ndaluara për kontakt

💾 Ruajtja e dataset-it të pastruar për analiza të mëtejshme
